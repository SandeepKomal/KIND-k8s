# Contributing

Contributions are welcome.

- Keep examples safe for local and CI environments.
- Never commit kubeconfigs, cloud credentials, tokens, passwords, or private keys.
- Prefer least-privilege RBAC and non-privileged workloads.
- Document prerequisites and cleanup for new labs.
- Validate Kubernetes YAML and shell syntax before opening a PR.

For every PR, describe what the example teaches, how it was tested, and any required tooling.
